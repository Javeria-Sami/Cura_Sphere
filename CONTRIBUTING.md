# Contributing

1. Read README.rm.
2. Read the relevant SRS section.
3. Read the feature flow.
4. Update Figma before implementation when UI changes.
5. Update database/API documentation for contract changes.
6. Implement as a vertical slice.
7. Add tests.
8. Run lint/build/tests.
9. Update changelog.
10. Open a pull request.

Do not commit secrets.
Do not bypass backend authorization.
Do not directly edit production data.
