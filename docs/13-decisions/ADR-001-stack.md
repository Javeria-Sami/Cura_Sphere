# ADR-001 — Technology Stack

Status: Accepted

Frontend:
React, TypeScript, Vite, Tailwind, shadcn/ui, Zustand, TanStack Query.

Backend:
ASP.NET Core, C#, EF Core.

Database:
PostgreSQL.

Real-time:
SignalR.

Reason:
The stack supports a typed, maintainable, scalable full-stack HMS with strong relational data handling and role-based workflows.
