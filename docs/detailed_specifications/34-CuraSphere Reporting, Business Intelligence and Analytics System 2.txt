5.12.10 Functional Requirement RBI-FR-006
Custom Report Builder

Requirement ID
RBI-FR-006
Requirement Name
Custom Report Builder

Description
The system shall provide an advanced Custom Report Builder that enables authorized users to create, modify, save, and execute customized reports without requiring software development.
Users shall be able to select data sources, fields, filters, sorting rules, grouping options, calculated fields, and visualization formats.

Actors

Department Manager
Finance Manager
HR Manager
Data Analyst
Authorized Users

Selected data source must be accessible.

5.12.19 Functional Requirement RBI-FR-015
Reporting Non-Functional Requirements
The Reporting module shall satisfy the following quality requirements.
Performance
Standard reports should typically generate within 5 seconds under normal operating conditions.
Complex analytical reports should complete within an acceptable configurable threshold.
Availability
Target availability: 99.9%, excluding planned maintenance.
Scalability
Support millions of historical records.
Support concurrent report execution by multiple users.
Reliability
Report generation shall not affect operational system performance beyond configured thresholds.
Security
All report access shall be audited.
Sensitive information shall be encrypted during transmission.
Backup
Report templates and scheduled configurations shall be included in system backups.
